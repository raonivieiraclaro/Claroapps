# Sonic MS Remake

Protótipo Android independente de plataforma 16-bit, criado como base técnica para um jogo inspirado nos clássicos de plataforma.

**Criador desta versão: Raoni Claro.**

Este repositório contém um **protótipo inicial**, não o remake completo. Não inclui sprites nem músicas da Sega. O título Sonic é marca de seus respectivos titulares; publicação comercial exige atenção aos direitos aplicáveis.

## Compilação

Em **Actions → Build Android APK → Run workflow**, execute a compilação. Quando ela terminar com sucesso, baixe o artefato `Sonic_MS_Remake_APK` da execução. O workflow ainda precisa ser validado em uma execução real.

## Controles

Setas para mover, Enter para pular; botões na tela para Android.
